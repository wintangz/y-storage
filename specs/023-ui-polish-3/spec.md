1. Binary `1 MB = 1_048_576 bytes` matches `format_size_2dec`'s binary units (`KB = 1024`, `MB = 1024^2`), so deltas `< 1_048_576 B` are never rendered as `KB`/`B` noise in the Growth delta column.
2. Settings omits the duplicate `draw_drive_pods_grid` band so `"Scan Scope & Exclusions"` (showing per-drive stats, `Include`, and exclusions) + `"Attribution Zone Rulebook"` + `"About"` fit without vertical clipping at `1020x720`.
3. `Xbox Service` (`C:\Program Files\XboxService\x64\XboxService.exe`) contains `0` embedded Win32 icons on disk, and scanning user `\AppData\` folders like `.minecraft` for service icons is explicitly disallowed, so it keeps the neutral fallback glyph.
