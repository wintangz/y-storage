# Feature Specification: `ledger-usability-1`

## Summary
Resolve six visual and interaction usability defects across the pinned storage ledger, the expanded Unattributed folder list, text-input hover cursors, the top drive pods, and general multi-facet filtering in the main app list — strictly visual/interaction changes with zero scan, attribution, or byte-total modifications.

## Scope (FIX 1–6)
1. **FIX 1 — Row Hover Highlight**: Reuse the main table's `pal.widget_hover` full-row hover fill on expanded ledger rows (`Unattributed` folder rows and `draw_simple_item_row` in `Windows & system`, `Your files`, `Shared & system caches`), keeping per-button `SubtleOutline` hover feedback intact on top. Documented in `DESIGN.md`.
2. **FIX 2 — Full-Height Ledger Resize**: Replace the `50%` window height cap with `ctx.available_rect().height() - 4.0` (client height minus header band minus `4px` grip clearance), clamping persisted heights on launch/resize and degrading `CentralPanel` gracefully down to `0` visible rows with zero negative rects or stuck splitters.
3. **FIX 3 — Search + Sort Inside Expanded Unattributed List**: Compact view-only filter input (`draw_crisp_text_input`, case-insensitive path/folder substring match), `Clear` button, 4-way sort selector (`Size ↓`, `Size ↑`, `Name A→Z`, `Name Z→A`), and live `"N of 303 folders · X.XX MB"` counter inside expanded `Unattributed`, keeping the group header total unfiltered and restoring the full list on collapse/clear.
4. **FIX 4 — Win32 `IDC_IBEAM` Text Cursor**: Emit `CursorIcon::Text` strictly across editable `draw_crisp_text_input` wells (`main_app_filter`, `unattrib_filter_input`, `rev_dep_search`, `exclusion_input`), disable accidental text cursor on static labels, and handle `WM_SETCURSOR` / `SetCursor(IDC_IBEAM)` in `win32_host.rs`.
5. **FIX 5 — Drive Pod Redesign (`DESIGN.md` Part II)**: Remove the glyph artifact and competing oversized free readout; render crisp `"C:\"` Strong `13.0pt` left title, unified `11.0pt Consolas Regular` `"{used} of {total}"` + muted `"{free} free"`, flush `2.0px` slim gradient bar (`PROP_BAR_H`) without outer ring/glow, standard `8.0px` `RADIUS_PANEL` + `1px pal.border`, and multiples-of-4 padding (`SPACE_12` / `SPACE_8`).
6. **FIX 6 — General Facet Filters**: Add 7 `SecondaryOutline` dropdown facet controls (`Publisher`, `Category`, `Drive`, `Size band`, `Dependency state`, `Footprint zone`, and conditional `Growth` when a prior baseline exists) combining via AND with filter chips and search text, persisted in `AppConfig` with missing-value fallback to `"All"`, wrapped cleanly across rows, plus `"Reset filters"`.
